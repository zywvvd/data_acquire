## 1. 成像原理与设备架构

### 1.1 结构光的两种架构

结构光的共同思想是主动投射已知图案、由相机观察求深度。按相机数量分两种:

| | 单目结构光 (monocular) | 双目结构光 / 主动双目 (active stereo) |
|---|---|---|
| 构成 | 1 投射器 + 1 相机 | 1 投射器 + 2 相机(立体对) |
| 测距 | 相机观察投射图案的形变,以「投射器-相机」基线三角测量 | 投射器投 IR 散斑作人工纹理,两相机做立体匹配(视差→深度) |
| 典型 | 初代 Kinect、RealSense F200 | RealSense D4xx、Apple TrueDepth、本设备 |
| 弱点 | 受环境光干扰较大 | 弱纹理/反光/透明面仍难匹配 |

主动双目即「结构光 + 立体匹配」:投射器不直接参与测距,仅提供人工纹理使左右相机得以建立对应关系。
本设备属此类(依据见 §1.2)。单目结构光亦可行,其深度公式与可行性见 §3。

### 1.2 本设备:光学布局与 SDK 组件

机身四个光学元件,加 SDK 暴露的一个计算组件,共 5 个组件(`DumpAllFeatures -ip .114` 实测):

| SDK 组件 (ID) | 角色 | 实测参数 |
|---|---|---|
| `TY_COMPONENT_LASER` (0x400000) | IR 散斑投射器(仅控制,不出图) | power=100,auto_ctrl=1,可读写 |
| `TY_COMPONENT_IR_CAM_LEFT` (0x40000) | 左 IR 相机 | 1280×960 mono8,fx=1102.09,exposure≤990,gain∈[0,255] |
| `TY_COMPONENT_IR_CAM_RIGHT` (0x80000) | 右 IR 相机 | 1280×960 mono8,fx=1104.60;右→左外参 tx=−99.89 mm(基线) |
| `TY_COMPONENT_DEPTH_CAM` (0x10000) | SGBM 深度输出(计算量,非光学件) | 320×240 / 640×480 / 1280×960 |
| `TY_COMPONENT_RGB_CAM` (0x100000) | RGB 相机(仅上色,不参与测距) | 2560×1920 |

判定为主动双目的依据:存在左右两个 IR 相机,且右相机带 `TY_STRUCT_EXTRINSIC_TO_DEPTH`
("rightIR to leftIR extrinsic"),平移分量 tx=−99.89 mm 即基线;深度组件下挂完整的 `TY_INT_SGBM_*`
参数(`DISPARITY_NUM`、`UNIQUE_FACTOR`、`LRC`、`MEDFILTER` 等),SGBM 为立体匹配算法,深度由左右 IR
匹配视差得到。RGB 与测距无关,仅经 `TYMapRGBImageToDepthCoordinate` 给点云上色。

接口代际为 **Gige_2_0**:`TY_COMPONENT_LASER` 的 `TY_INT_LASER_POWER` / `TY_BOOL_LASER_AUTO_CTRL`
均 access=3(可读写),走旧 `TYSetInt/TYSetBool` API,非 Gige_2_1 的 GenICam 接口
(`LightControllerSelector`/`TYParamGetAccess`)。SDK 对 LASER/IR 的设置均有效。

### 1.3 散斑:作用与必要性

投射器内置衍射光学元件(DOE),将红外激光打散为大量随机分布的 IR 亮点投到场景,即散斑。该图案为静态
(每次投射同一份点阵),对人眼与 RGB 相机不可见,左右 IR 相机可清晰成像(见图 §1.4)。

立体匹配需在左右两幅图中找到同一批点的对应关系。白墙、桌面等无明显纹理的区域在左右图中皆均匀,无法建立
对应(弱纹理失配)。散斑为整个场景叠加一层人工纹理,每个小区域获得独一无二的随机点阵,使匹配成为可能。
关掉投射器后深度有效率由 33% 降至 2%(§8.1),即散斑是匹配纹理的主要来源。

### 1.4 立体匹配与深度流水线

深度测量的核心是测定同一 3D 点在左右两幅 IR 图中的水平位置差(视差):

```
            投射器(固定散斑图案)
                │
        ┌───────┴───────┐
   左 IR 图  ←P at x_L   右 IR 图  ←P at x_R
        └───────┬───────┘
                ▼
        视差 d = x_L − x_R   ──►   深度 Z = f·B/d
```

同一物点 P,左相机成像于 `x_L`,右相机成像于 `x_R`,二者水平位置之差 `d = x_L − x_R` 为视差。P 越近视差
越大,越远视差越小(趋近 0)。由几何关系 `Z = f·B/d` 换算为深度(推导见 §2.2)。

整流(rectify):出厂标定将左右 IR 图变换到「对应点落在同一行」的坐标系(epipolar 约束),匹配由二维搜索
降为沿同一行的一维搜索。SGBM 对左图每个像素,在右图同一行的有限视差窗内搜索最相似块(以散斑纹理为相似度
依据),位移量即视差;视差窗的具体范围决定量程(§4)。采用随机点阵而非条纹/网格,因随机分布使每个小窗口
图案唯一,避免歧义匹配。

完整流水线:

```
投射散斑 ─► 左IR ┐
                  ├─► SGBM(1D 视差搜索)─► 视差图 ─► Z=fB/d ─► 深度图 ┐
投射散斑 ─► 右IR ┘                                                    ├─► 上色点云
                                          RGB ─► 贴色到深度点 ─────────┘
```

同一位置采集的各环节实例:

![散斑结构光成像流水线](assets/speckle_pipeline.png)

上图中左右 IR 散斑为同一片点阵(水平错开,即立体匹配的输入),经 SGBM 得深度图,再以 RGB 上色为点云。
RGB 面板看不到散斑(红外不可见),而深度与点云的获得均依赖它。

## 2. 深度几何:双目立体视觉推导

### 2.0 符号约定

下表符号贯穿 §2 与 §3。

| 符号 | 含义 | 单位 |
|---|---|---|
| `P = (X, Y, Z)` | 空间物点的三维坐标(相机坐标系) | mm |
| `Z` | 深度:物点沿光轴方向的距离 | mm |
| `X`, `Y` | 物点的横向 / 纵向坐标 | mm |
| `f` | 焦距(以像素计 = 物理焦距 ÷ 像素尺寸;标定给出) | px |
| `B` | 基线:两光心的横向间距(双目=左右相机;单目=相机↔投射器) | mm |
| `d` | 视差:同一物点在两幅图中的水平位置差 | px |
| `x_L, y_L` / `x_R, y_R` | P 在左 / 右相机图像中的像素坐标 | px |
| `u_c` / `u_p` | (单目)相机像列 / 投射器已知的投射列 | px |
| `σ_d` | 子像素视差噪声(单次匹配的视差抖动,§2.5) | px |
| `ΔZ` | 每 1 视差像素对应的深度增量(§2.4) | mm |

坐标系:原点在左相机光心(双目)或相机光心(单目);`+Z` 沿光轴(深度方向);`+X` 沿基线方向;`+Y` 纵向。
像坐标以主点(光轴与像面交点)为原点,单位像素。量纲自洽:`Z = f·B/d` → `px·mm/px = mm`。

### 2.1 针孔成像与深度的丢失

相机成像的基础是针孔模型:将相机简化为一个光心 O 与一个像面,物点 P 发出的光经 O 在像面上落点 p 成像。
建立相机坐标系,O 为原点,Z 轴沿光轴(相机朝向),像面位于 z=f 处,f 为焦距。在 X-Z 平面内,物点 P=(X,Z)
的光线 OP 与像面 z=f 的交点 p 的横坐标为 x,由相似三角形(小三角形 O-f-x 与大三角形 O-Z-X 同构):
```
   x / f = X / Z   ⇒   x = f · X / Z        (纵向同理  y = f · Y / Z)
```
此即针孔投影:3D 点 (X,Y,Z) 投到像点 (fX/Z, fY/Z)。

![针孔相机模型:相似三角形 x/f = X/Z,深度 Z 在投影中丢失](assets/pinhole_model.png)

关键:投影把三维坐标 (X,Y,Z) 压成二维 (x,y),Z 在此过程中消失——同一条光线 OP 上远近不同的物点都投到
同一个像点 p。因此单张图像无法区分「近处的小物」与「远处的大物」,这是单目不能测距的根本原因。

恢复距离需引入第二个观察点做三角测量:两个相机从不同位置观察同一物点,各得到一条指向它的光线,两线交点即
物点的 3D 位置;物点在两幅图中的位置差(视差)编码距离,此为双目立体视觉原理(人眼同此理)。本设备的两个
IR 相机加基线即构成双目。(若第二个观察点换成图案已知的投射器,则为单目结构光,见 §3。)

### 2.2 双目深度公式 Z = f·B/d 的推导

几何假设(整流后的标准姿态,见 §2.5):
1. 左右两相机焦距相同,均为 `f`;
2. 两相机光轴平行,均指向 `+Z`;
3. 两光心在同一水平线,横向间距为基线 `B`;
4. 左光心在原点 `(0,0,0)`,右光心在 `(B,0,0)`。

俯视图(两相机光心、基线 B、物点 P 与两条成像光线):

![双目三角测量:两条光线交于物点 P,水平位置差即视差 d](assets/stereo_triangulation.png)

针孔模型中,3D 点 `(X,Y,Z)` 投影到像点 `(x,y)`,由相似三角形(像高/焦距 = 物高/物距):
```
   x = f · X / Z ,   y = f · Y / Z
```
P 在左相机(光心在原点)的像坐标:
```
   x_L = f · X / Z
   y_L = f · Y / Z
```
右相机横向偏移 B,P 在右相机坐标系横坐标为 (X−B):
```
   x_R = f · (X − B) / Z
   y_R = f · Y / Z = y_L   （纵坐标相同 = 对应点同行 = epipolar 约束）
```
视差 `d` 为同一 P 在左右图中的水平位置差:
```
   d = x_L − x_R = f·X/Z − f·(X−B)/Z = f·B / Z
```
解出深度:
```
        f · B
   Z = ───────
          d
```
`f`、`B` 为相机固定常数(标定得到),`d` 由两幅图测得。此即双目深度基本公式。P 移近(Z 减小)→ `d=fB/Z` 增大,
移远 → `d` 减小,故视差大对应近、小对应远。

本设备数值:`f` = 1102.09 px,`B` = 99.89 mm,`f·B` ≈ 110 080 mm²。示例:1 m 处 `d≈110 px`,
0.6 m 处 `d≈187`,4 m 处 `d≈27`。

视场 FOV 由焦距与分辨率给出:`HFOV = 2·atan(W/(2f)) = 2·atan(640/1102.09) = 60.2°`,
`VFOV = 2·atan(480/1102.23) = 47.1°`。点云呈以相机为顶点的扇形径向展开,即此视场锥的几何表现——
每像素对应一条射线,场景在角域内铺开(故点云观感呈放射状,属投影几何,非畸变)。

**对应问题(立体匹配)**:`Z=fB/d` 的前提是已知同一物点 P 在左右图中的像点 x_L 与 x_R 对应同一物点。但左右图
各有上百万像素,哪个左像素对应哪个右像素并非给定,需在两幅图中搜索——此即对应问题,是双目视觉的计算核心。
匹配依赖图像纹理:在白墙等无纹理区域,左右图皆均匀,无法判定对应。本设备以散斑(§1.3)补充纹理、以 SGBM
算法(§1.4)求解;整流(§2.5)把对应点约束到同一行,使搜索从二维降为一维。视差搜索只能在有限窗内进行,
该窗口决定量程(§4)。

### 2.3 三维坐标三角化(点云)

Z 已知后,X、Y 由左图像坐标反推(针孔投影的逆):
```
   X = x_L · Z / f ,   Y = y_L · Z / f
```
每个深度像素 (x_L, y_L) 与其 Z 组合为一个 3D 点 (X,Y,Z),全图遍历即得点云。本设备由
`TYMapDepthImageToPoint3d` 依深度相机内参完成。

Z 为轴向深度(沿光轴的垂直距离),即 `d=fB/Z` 直接给出的量,非斜距;设备 `depth` 图即存此轴向 z
(§7.2 实测 `depth` 与点云 z 相等)。轴向深度只随物体远近变化,与像素位置无关,故平墙的轴向深度近似常数。

### 2.4 深度精度 ΔZ = Z²/(f·B)

对 `Z = f·B/d` 求视差 d 的微分,含义为视差每抖动 `dd` 像素引起的深度误差 `dZ`:
```
   Z = f·B / d
   dZ/dd = − f·B / d²
   |dZ|  = (f·B/d²)·|dd| = (f·B/d)²/(f·B)·|dd| = Z²/(f·B)·|dd|
```
视差每差 1 像素(`|dd|=1`),深度差:
```
   ΔZ = Z² / (f·B)
```
代入 `f·B = 110 080`:

| 距离 Z | ΔZ(每视差像素) |
|---|---|
| 0.6 m | 3.3 mm |
| 1.0 m | 9.1 mm |
| 2.0 m | 36 mm |
| 3.0 m | 82 mm |

深度被视差量化,视差每跳 1 像素深度跳 `ΔZ`。因 `ΔZ ∝ Z²`,深度精度随距离平方退化,此为双目(及一切三角
测距)的几何属性。

### 2.5 子像素与整流

§2.4 的 `ΔZ` 为整数视差步长(1 m 处约 9 mm/格),实际 SGBM 做子像素(sub-pixel)匹配:通过块相关度的
亚像素插值,视差精度可达 0.1 像素量级。设子像素视差噪声为 `σ_d`(像素),则深度噪声:
```
   深度噪声 RMS ≈ σ_d · Z² / (f·B)
```
实测反推(§5):1–3.3 m 段 `σ_d` ≈ 0.114–0.138 px,中位 0.126 px,几乎与距离无关;深度噪声即
0.126 × ΔZ,继承 `ΔZ ∝ Z²`。

整流(rectification)即 §2.2 假设的来源:实际两相机并非严格平行同行,出厂标定对左右 IR 图各做一次单应
变换,映射到「对应点同行」的标准姿态,使立体匹配成为沿行的一维搜索。

![整流:把两幅图变换到对应点同行,匹配由二维搜索降为一维](assets/rectification.png)

设备内部已完成整流,故 §2.2 推导成立。
整流同时消除 IR 镜头畸变,这是点云几何干净、仅 RGB 颜色带畸变的原因(§7.2)。

## 3. 单目结构光对照

§1.1 提到结构光的另一种架构为单目。单目结构光理论上可行,且为成熟技术(初代 Kinect、RealSense F200、
多数工业条纹扫描仪)。

其测距方式:1 个投射器 + 1 个相机;投射器投一幅已知图案(每个点/条纹的身份与位置已知),相机观察该图案
被 3D 表面调制后的形态。因图案已知,系统将投射器视为第二只「虚拟眼」,在「投射器↔相机」间做三角测量:
相机图中的某点对应已知的某个投射图案特征,连同几何关系即可解出深度。

**深度公式推导**(单目在几何上等价于「双目中以图案已知的投射器替换一只相机」;符号见 §2.0)。设投射器与
相机光轴平行、横向相距基线 B,焦距同为 f。相机中心在原点,投射器中心在 (B,0,0),均朝 +Z。将投射器视为
逆相机,其「成像」即它投出的已知图案。对空间点 P=(X,Y,Z):

- 相机观察到的像列:`u_c = f · X / Z`
- P 在投射器坐标系横坐标为 (X−B),其已知的投射列:`u_p = f · (X − B) / Z`

两者之差:
```
   d = u_c − u_p = f·X/Z − f·(X−B)/Z = f·B / Z   ⇒   Z = f·B / d
```
与双目形式一致 `Z=fB/d`。差异仅在于视差 `d` 的获取:

| | 视差来源 | 对应关系的建立 |
|---|---|---|
| 双目(本设备) | `d = u_c − u_另一相机像素` | 在两幅相机图中搜索(SGBM 块匹配) |
| 单目 | `d = u_c − u_p`(`u_p` 已知) | 不搜索两幅图,但需先识别相机图中该点对应投射图案的哪一点 → 得到 `u_p` |

`u_p` 已知化的三种主流方案,决定单目结构光的形态:
1. 空间编码图案:每个投射像素图案唯一(De Bruijn 序列、彩色编码、Gray 码条纹),相机观察后直接解码 → `u_p`;单次拍摄。
2. 相移条纹:投多幅相移正弦条纹,逐像素求相位 → 映射到 `u_p`;多次拍摄,近场精度可达微米级。
3. 固定散斑 + 参考图(Kinect v1 的 light-coding):投固定随机散斑,先在已知距离 `Z_ref` 存参考散斑图;
   运行时将观测散斑与参考散斑做块匹配,位移为 `(d − d_ref)`,由 `Z = fB / (d_ref + 位移)` 反算。
   此法本质是以参考图充当第二幅图的双目匹配。

精度仍为 `ΔZ = Z²/(f·B)`——三角几何不区分「相机↔相机」与「相机↔投射器」,故单目结构光精度同样随 Z² 退化。
量程受限于相机 FOV 与投射器 FOV 的交集及图案可解码范围。

单目与双目的主要差异:

| | 单目结构光 | 双目结构光(本设备) |
|---|---|---|
| 三角测量对象 | 投射器 ↔ 相机 | 左相机 ↔ 右相机 |
| 投射图案要求 | 已知 / 编码(每特征具唯一身份) | 随机散斑即可(仅作纹理) |
| 投射器是否需标定 | 是(作虚拟相机,标定较难) | 否(仅作照明) |
| 典型产品 | Kinect v1、RealSense F200、工业条纹扫描仪 | RealSense D4xx、本设备、TrueDepth |

就本设备而言,若仅保留一只 IR 相机(改为单目),能否测距取决于投射器:现为随机散斑,单相机所获为一组无
身份的点,无法与投射器建立对应、无法三角,不能测距;除非额外存参考散斑图(light-coding)或改用编码图案。
现代消费级深度相机多采用主动双目,原因在于工程取舍:一片廉价的随机散斑投射器(无需编码、无需标定)配合两台
相机做匹配,制造简单、成本低、对投射器漂移较鲁棒;单目方案则需解决图案身份识别与投射器标定,复杂度更高。
本设备选用双目属工程取舍,并非单目在理论上不可行。

## 4. 工作量程

### 4.1 近/远端极限的计算

近/远端极限 = 视差搜索窗的上下界经 `Z=fB/d` 换算。SGBM 仅在有限视差窗内搜索,实测
`DISPARITY_OFFSET=25`、`DISPARITY_NUM=162`,即 `d ∈ [25, 187]`;超出此窗则匹配失败、深度无效:
```
   Z_min = f·B / d_max = 110080 / 187 ≈ 589 mm  ≈ 0.59 m
   Z_max = f·B / d_min = 110080 / 25  ≈ 4403 mm ≈ 4.41 m
```

![视差-距离曲线与搜索窗:窗 [25,187] px 对应量程 0.59–4.4 m](assets/disparity_range.png)

工作量程约 **0.59–4.4 m**。实测深度有效值落在 558–4164 mm,处于理论区间内(极端视差处匹配稀疏,略收缩)。

量程为有限窗而非无穷的原因:视差越大搜索越慢且易越界;视差过小则基线相对距离过短,三角测量失效。
`[25,187]`(对应 0.59–4.4 m)为出厂针对典型用途的折中。量程应以视差窗与 `fB/d` 的几何推导为准,
而非从数据有效值上下界反推(后者为循环论证)。

### 4.2 越界实测

将相机正对一面平墙,由 0.5 m 逐步移至 4.5 m,记录深度有效率(`depth>0` 像素占比):

| 距离 | 有效率 | 现象 |
|---|---|---|
| 0.5 m | 6.7% | 墙体 0.5 m < 近端 0.59 m,整面墙深度无效,残存 6.7% 为墙后背景 |
| 0.6–3.7 m | 75–91% | 量程内,墙体完整可测 |
| 4.5 m | 36.2% | 墙体 4.5 m > 远端 4.4 m,墙体无效,残存 36% 为近处地板/天花板/侧墙 |

两端越界时墙体本身在深度图中消失,与 §4.1 推得的 0.59 m / 4.4 m 边界吻合(完整曲线见图 §5.2)。

### 4.3 量程调整途径

- 软件:修改 `DISPARITY_OFFSET`(下界)/ `DISPARITY_NUM`(窗宽)可移动或展宽量程,代价为匹配速度与歧义;
  该参数是否开放写入视固件而定。
- 硬件:量程 ∝ f·B,更长焦距或更长基线的设备可整体外推量程。本设备固定。

## 5. 距离-精度实测

> 配图:`assets/precision_vs_distance.png`(精度与有效率曲线,9 点含两端越界)、
> `assets/flatness_map.png`(单距离平整度热力图与残差直方图)、`assets/precision_results.csv`(原始数据)。
> 采集于 `data/fm815_precision/d{0.5..4.5}m/`,各含 depth/color/点云 + flatness.txt。

### 5.1 方法:MAD 鲁棒平面拟合

正对一面平墙,在不同距离各采 3 帧(1280×960),以点云到拟合平面的残差衡量平整度。

关键在于仅统计墙体上的点:距离较远时视场溢出墙体,地板/天花板等非墙点会污染结果(曾因此将 2.5 m 的
RMS 误算为 94 mm)。方法:
1. 由深度直方图确定墙的尖峰(轴向深度众数),取 ±120 mm 窗剔除远处背景;
2. 对窗内点以 MAD(中位绝对偏差)鲁棒迭代拟合主平面,并校验正对(`|法向·z 轴|>0.9`);
3. 取 3×MAD 内点为真墙点,重拟合后计算 RMS / P95。

MAD 较标准差抗污染,远处散乱背景不会抬高阈值。各距离结果存于 `flatness.txt`。

### 5.3 印证:反推子像素 σ_d ≈ 0.13 px

由 §2.5,RMS = σ_d·Z²/(fB)。以实测 RMS 反推 σ_d(上表末列):1–3.3 m 段 σ_d = 0.114–0.138 px,
中位 0.126 px,近似恒定。单次立体匹配的视差抖动稳定在约 0.13 像素,与距离无关;深度噪声完全继承
`ΔZ ∝ Z²`。图中虚线为理论曲线 `0.126·Z²/(fB)`,与实测点吻合——精度随距离平方退化可由 f、B、σ_d 三者
推导得出并被数据印证。

### 5.4 近端地板与远端平台

- 近端 0.63 m 处 σ_d=0.181 偏高:极近距离下除视差量化外,传感器读噪声等贡献约 0.4–0.5 mm 的近端地板,
  RMS 略高于纯 Z² 预测。
- 远端 3.3–3.7 m 处 σ_d 降至 0.099,RMS 趋于平台(12.3 → 12.5 mm):接近远端极限时较差的匹配率先变为
  无效并被剔除,存活的匹配质量较好,RMS 不再增长,但有效率明显下滑(90% → 78% → 75%)。即越过约 3 m 后
  精度不再换取改善,仅损失覆盖率。

综合两项,精度可近似为:
```
   RMS(Z) ≈ √( (σ_d·Z²/(fB))² + z_floor² ) ,  σ_d ≈ 0.126 px , z_floor ≈ 0.47 mm
```
近距由 z_floor 主导,中远距由 Z² 项主导。

多帧时间稳定性(同一摆位连采多帧):逐像素深度的时间抖动约 0.5 mm,相邻帧残差相关 ≈1.0,表明单帧 RMS 的
主体为固定系统性图案(视差量化网格 + 整流残余),时间随机成分仅约 0.5 mm。因此多帧平均对精度改善有限,
降低 RMS 的有效途径是减小工作距离(精度 ∝ Z²)而非累加帧数。

### 5.5 距离选型

| 距离 | 精度 (RMS) | 适用 |
|---|---|---|
| 0.6–1 m | 0.7–1.3 mm | 亚毫米至毫米级精密测量 |
| 1–2 m | 1.3–4.6 mm | 兼顾精度与覆盖的折中区,有效率 >90% |
| 2–3 m | 4.6–12 mm | 厘米级,可用 |
| >3 m | 约 12 mm,有效率下降 | 不建议 |

选型原则:按所需精度倒推安装距离(精度 ∝ Z²);毫米级安装于 1–2 m,亚毫米级靠近至 0.6 m。
远距离大范围感知宜用 LiDAR(见附录)。

## 6. 点云密度与采集配置

### 6.1 点云稀疏的来源

深度有效率不高的来源,按可调性排列:

**(a) 场景与量程(影响最大)**:相机平放桌面时,正下方/前景小于 0.59 m 的区域整块无效(视差超搜索窗,§4)。
实测平放(前景过近)有效率 6.8%;摆位使目标落入 0.6–4 m 有效区后升至 33%(640×480)或更高(1280×960)。

**(b) 分辨率模式**:`get_default_image_mode` 默认返回 640×480(原生 1280×960 的降采样)。改为 1280×960 后
有效率几乎不变,点数提升 4 倍,精度不降。佐证:640 模式 fx=522.43,恰为 1280 模式 fx(1102.09)之半。

**(c) SGBM 严苛度(密度/精度折中)**:默认偏重精度,`UNIQUE_FACTOR=80`、`LRC=on`(左右一致性,剔除遮挡与
误匹配)、中值滤波。放宽至 `UNIQUE_FACTOR=20` 并关闭 LRC,有效率由 33% 升至 47%,但误匹配增多、遮挡剔除
丧失,精度下降。需精度时保留默认,需密度时再放宽。

**(d) IR 增益(默认即最优)**:出厂默认 gain=32。增益扫描(以深度有效率为指标):32→33.5%,64→25.8%,
128→1.3%,200→0%,调高反而变差(饱和与噪声破坏匹配纹理)。`-ir` 直存的 IR 帧全黑(max≈14)并非增益或
曝光不足,而是 depth+IR 同开时激光同步绑定至 depth、IR 组件取到灭灯相位所致(§8.2),增益对此类帧无响应。
LASER_POWER、gain 等设置会持久化存入设备,改动后需显式重置(gain→32,laser→power100/auto1)。

**(e) 表面材质(无法消除)**:玻璃、屏幕、黑色、强反光面不能返回有效 IR 散斑,深度恒为无效。

### 6.2 采集配置建议

1. depth 使用 1280×960,`-dmode 1280`;
2. SGBM 保留默认;仅在明确需要密度时使用 `-uniq 20 -nolrc`;
3. gain 保持 32,勿扫描;若被改动过,先重置;
4. 摆位使目标落入 0.6–4 m,避开屏幕/玻璃/强反光面,采用漫射光;
5. 按精度需求选定距离(§5.5),毫米级安装于 1–2 m;
6. 批量采集:
   ```
   SimpleView_CaptureDump -ip 192.168.1.114 -n 6 -dmode 1280 -outdir <dir>
   ```

`main.cpp` 诊断/调参开关:`-dmode 1280`、`-ire/-irg`(IR 曝光·增益)、`-uniq/-nolrc`(SGBM 严苛度)、
`-ir`(同开 IR,见 §8.2)、`-laser <0..100>` + `-lauto <0|1>`(投射器功率/频闪)、`-nodepth`(纯 IR)、
`-irflash`(本设备无效)。每帧统计深度有效率,启动时打印 `LASER now: power=X auto=Y`。

## 7. 标定与畸变

### 7.1 出厂标定与可自标性

设备出厂标定存于各组件 `TY_STRUCT_CAM_CALIB_DATA`,`access=1`(只读),API 不能写回设备。重新标定只能于
主机端读出后以自有标定覆盖重算,SDK 内置函数仍用设备原标定。

| 标定项 | 影响 | 能否自标 | 方法 |
|---|---|---|---|
| RGB 内参 + 畸变 | 彩色上色/对齐 | 能,较易 | 棋盘格/Charuco + OpenCV `calibrateCamera`,主机端覆盖 `color_calib` |
| IR 内参 + 畸变 | 深度几何 | 能,较繁 | 关投射器,以外部 IR 补光(本设备无 IR 泛光灯,需自备)照明棋盘格 |
| 双目外参(基线/整流) | 深度量程精度(关键) | 实际不能 | 出厂锁死;SDK 于设备端执行 SGBM,无法注入。覆盖需自拍左右 IR、自整流、自立体匹配,等同重写深度引擎 |
| depth↔RGB 外参 | 彩色贴图对齐 | 能 | SDK 自带 `SimpleView_Registration` / `SimpleView_PixelsRegistration` |

### 7.2 RGB 镜头畸变(点云中直线弯曲的成因与处理)

带色点云中墙上直线(凹槽)呈现弯曲,且弯曲形态与彩色图一致。

两种易致误判的度量:点到平面平整度(§5 约 1.4 mm)衡量的是离面 z 残差,对平面内桶形畸变(将直线在平面内
弯折,z 几乎不变)不敏感;针孔拟合残差——点云本身由 `X=(u-cx)·Z/fx` 生成,以此式反拟合残差必然为 0,属循环
论证。正确判据为直线特征:以已知为直线的凹槽检验其是否弯折。

诊断(弯曲来自颜色,非几何):在 CloudCompare 中关闭点云 RGB、改按高度上色后,凹槽即变直,表明几何无畸变,
弯曲来自颜色。几何保持干净的原因:双目深度在校正后的图上计算,IR 镜头畸变已被整流消除;`depth` 存的是轴向 z
(实测 `|depth − 点云.z| = 0.00 mm`),点云为干净针孔,直线不弯。颜色弯曲的原因:RGB 为独立镜头,带桶形畸变;
解码所得 BGR 携带该畸变,贴到干净几何上,凹槽(以颜色才可见)随之弯曲。图像与点云弯曲一致,即源于同一份
RGB 镜头畸变。

RGB 畸变系数(读出厂标定):
```c
TY_CAMERA_CALIB_INFO color_calib;
TYGetStruct(hDevice, TY_COMPONENT_RGB_CAM, TY_STRUCT_CAM_CALIB_DATA, &color_calib, sizeof(color_calib));
```
`TY_CAMERA_CALIB_INFO` 含 `intrinsic.data[9]`(3×3:[fx,0,cx,0,fy,cy,0,0,1])与 `distortion.data[12]`
(Percipio 自定义 12 系数模型,非 OpenCV 的 5/8 系数)。本机实测 intrinsic fx=1864.8、fy=1865.3、
cx=1278.9、cy=955.2;distortion 前 6 项 `-0.2334, 0.4031, -0.0002, 0.0004, 0.2073, 0.0268`
(首项 k1=−0.2334,负值即桶形)。`main.cpp` 启动时打印此组系数。

去畸变(使用 SDK 接口;Percipio 为 12 系数自定义模型,与 OpenCV 的 5/8 系数不匹配,用 `TYUndistortImage`):
```c
// 1) 解码 BGR 后以 color_calib 去畸变(NULL 新内参 = 保持原 fx/fy/cx/cy,输出 pinhole 图)
TYUndistortImage(&color_calib, &srcImg, NULL, &dstImg, TY_LENS_PINHOLE);
// 2) 贴点云时 color_calib 畸变清零(图已是 pinhole,避免映射函数二次校正)
TY_CAMERA_CALIB_INFO calib_pin = color_calib;
memset(&calib_pin.distortion, 0, sizeof(calib_pin.distortion));
TYMapRGBImageToDepthCoordinate(&depth_calib, ..., &calib_pin, ..., mappedColor, ...);
```
要点:仅对 RGB 去畸变(depth/IR 已整流);去畸变后图为 pinhole,贴图所用 calib 须清零畸变;去畸变在存 JPG
之前完成,故存盘的 `color_*.jpg` 一并去畸变。

![去畸变后的带色点云正视图(墙上直线已直)](assets/colored_front.png)

### 7.3 深度标定准确性

现有证据表明深度标定准确:1 m 处平整度 1.4 mm(§5),量程与 `fB/d` 推导吻合(§4),`depth` 等于轴向 z。
唯一发现的问题为 RGB 镜头畸变(§7.2),属 RGB 相机,与深度标定无关。判定标定问题前宜先以已知尺寸核验
(误差应 <1%);若量测一致,无需改动深度标定。应考虑重标的情形:量测明显偏差(深度量程问题,但双目外参
不可自标,需返厂或用 Viewer 重标)、彩色整片对不齐(标 RGB)、相机曾受磕碰(标定漂移)。

## 8. 投射器与 IR 成像特性

### 8.1 投射器发射验证

散斑投射器为立体匹配提供人工纹理。对照实验(同摆位,640×480,各 3 帧平均):

| LASER 配置 | 深度有效率 |
|---|---|
| power=100,auto=1(出厂频闪) | 33.4% |
| power=100,auto=0(手动常亮) | 33.2% |
| power=0(关闭) | 2.4% |

关闭投射器后深度由 33% 降至 2%,即散斑是匹配纹理的来源,投射器工作正常。`TYSetInt(TY_COMPONENT_LASER,
TY_INT_LASER_POWER, …)` 读回 0↔100 正确且深度随之响应,旧 API 有效(接口代际 Gige_2_0 见 §1.2)。

`LASER_POWER` 持久化存储。实验后须以 `-laser 100 -lauto 1` 恢复,否则下次不带 `-laser` 的采集会沿用残留的
power=0,导致深度归零。`main.cpp` 每次启动打印 `LASER now: power=X auto=Y` 供核查。

### 8.2 depth+IR 同开时 IR 帧全黑的原因

`-ir`(同时开启 depth 与左右 IR)所存 `ir_left/right_*.png` 长期 max≈14/255,gain 0→255 无响应。此非故障,
而由光照路由所致:投射器光照仅路由至主流量。depth 与 IR 同开时,激光频闪绑定至 depth 时序,深度引擎在亮帧
时刻内部取走 IR 图用于匹配;旁路开启的 `IR_CAM_LEFT/RIGHT` 在另一时刻取图,取到灭灯相位,故全黑且无光可放大。

| 模式 | 投射器 | IR 帧 mean / max / std |
|---|---|---|
| depth + IR 同开(`-ir`) | 开 | 7 / 14 / 5(黑) |
| depth + IR 同开(`-ir`) | 关 | 7 / 14 / 5(黑) |
| IR-only(`-nodepth`) | 开 | 199 / 255 / 78(亮) |
| IR-only(`-nodepth`) | 关 | 19 / 50 / 2(黑) |

IR-only 且投射器开启时 IR 帧全亮,Laplacian 纹理方差 646(暗帧为 105,约 6 倍),可见高密度随机点散斑。

![IR-only 模式采集的左右 IR 原始散斑](assets/speckle_left_vis.png)

本设备无独立 IR 泛光灯(`TY_BOOL_IR_FLASHLIGHT` 于各组件 `TYHasFeature=false`)。采集真散斑:

## 附录:与 LiDAR 的定位差异

LiDAR(禾赛/速腾/Livox)以飞行时间(ToF,直接测光往返)测距,每点独立、稀疏但远(百米级)。本设备以双目
立体匹配(投射器仅补纹理)获得稠密深度图(每像素一个深度),受基线限制量程短(米级)、受表面反射率影响大。
二者互补:LiDAR 远而稀,结构光近而密。本仓库 7 路设备中,此结构光负责近场稠密 3D,远距离大范围感知由 LiDAR 承担。
