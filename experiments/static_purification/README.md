# 静态多帧净化对雷达外参标定的影响评估

> 评估「静态场景下多帧融合净化」对多传感器外参标定**精密度**与**准确度**的提升,定量回答:
> **融合多少帧够用?每台传感器各自的收益曲线长什么样?净化到什么程度就触顶(被偏差主导)?**
>
> 本文档是方案与原理(讨论结论),不含实现代码。实现脚本后续放在本目录下(`fuse.py` / `register.py` / `eval.py` / 结果图)。

---

## 0. 一句话目的

用「5 传感器 × 100 静态帧」数据(禾赛 QT128 / 速腾 RSAIRY ×2 / Livox HAP / 图漾结构光),把每台各炼成不同帧数 $k$ 的净化点云,在**固定的高质量参考系**下做外参标定,刻画**精密度/准确度随 $k$ 的变化曲线**,并区分「重复性」与「真值准确度」。

> **物理绝对锚(房间角)**:本次采的是标定数据;若场景含可用三面角且在「所有 LiDAR ∩ 结构光」公共视场内,可直接用于 §6.3 的绝对准确度校验;否则按 §13 的清单补采(把房间角摆进公共视场)。

### 1.2 为什么静态数据能做外参标定
静态场景下,**每台传感器的同一条射线/同一个像素,在 100 帧里打的是同一个世界点**。于是可按「射线/像素」聚合并统计,把噪声降到 $\sigma/\sqrt{N}$,得到一张干净稠密的参考云;再在云与云之间做刚体配准求外参。这是 **targetless、基于场景配准**的成熟外参标定路线。

### 1.3 静态数据的边界(能 / 不能)
| 能做 | 不能做(仅凭静态无靶标) |
|---|---|
| **外参标定**(传感器间 6-DoF 刚体变换),基于配准 | **内参标定**(逐光束角/距离改正),需靶标或运动 |
| **精密度**(重复性)随帧数的曲线 | **绝对准确度**的真值校验——除非引入已知几何参考(房间角) |

> ⚠️ 全文反复出现的核心区分:**精密度(precision,重复性)≠ 准确度(accuracy,逼近真值)**。$\sigma/\sqrt{k}$ 是精密度律,系统偏差不随 $k$ 减小。本实验两者都量,但必须分开报。

## 2. 核心原理

### 2.1 净化的数学本质:$\sigma/\sqrt{N}$
静态场景、固定安装下,同一(射线/像素)桶在 $N$ 帧里采到同一世界点的 $N$ 个带噪样本。取均值/中值:
$$\sigma_{\text{fused}} = \frac{\sigma_{\text{single}}}{\sqrt{N}} \quad(\text{独立样本、均值情形})$$
机械雷达 100 帧 → 约 10× 降噪;中值情形方向一致但对外点更鲁棒。

### 2.2 不同传感器的「桶」不同(关键)
| 传感器类型 | 扫描特性 | 净化域 | 桶定义 |
|---|---|---|---|
| 机械雷达(禾赛/速腾) | 固定线束旋转,重复 | **角度域** | (ring, azimuth);速腾无 ring 字段则用 (方位角 bin, 俯仰角 bin) 由 xyz 反算 |
| 固态(Livox HAP) | 双棱镜 rosette,**非重复** | **空间体素域** | 3D voxel(无固定射线,靠累积填满视场) |
| 结构光(FM815) | 全像素深度图,每像素固定射线 | **深度图域** | 像素 $(u,v)$;逐像素对有效帧取中值,再反投影 |

> 三者本质同构(同一世界点多帧统计),只是「桶」的几何不同。结构光的桶最规则稠密,时域中值就像给深度图拍长曝光。

### 2.3 边缘混合坑(三者共性)
深度跳变处,一个桶跨帧可能在前/背景间**双峰跳变**(机械雷达边缘桶、结构光 flying pixel)。对策:**用中位数**,别用均值(均值造鬼点);可加 IQR/双峰检测剔异常桶。角棱/边缘是全场最脏的区域,量**离棱几厘米的平面区**,别量棱线本身。

### 2.4 为什么「先融合再配准」优于「逐帧配准再平均」
两种朴素方案:
- **方案 A(参数层平均)**:逐帧各跑一次配准 → $N$ 个外参 $T_i$ → 平均。
- **方案 B(测量层平均)**:先融合成一张干净云 → 一次配准 → 一个 $T$。

**选方案 B**,理由:
1. **偏差不随平均消失**:单帧稀疏+噪声使配准落进**系统性偏差**(确定性,同场景同极小值),$N$ 个偏的估计取平均仍是那个偏。方案 A 只降方差、不降偏差;方案 B 靠**稠密化**让配准收敛更接近全局最优 → **偏差也降**。
2. **方案 B 更接近最大似然估计**(一次联合拟合,充分利用跨帧几何一致性)。
3. 方案 A 还有:旋转平均的坑(不在向量空间,欧拉角平均有偏)、帧间相关使 $\sigma/\sqrt{N}$ 高估、R/t 耦合丢失。
- 方案 A 的**唯一价值**是 $T_i$ 的散布作为**精密度诊断**——所以最终是「方案 B 出结果 + 方案 A 的分布报精密度」。

## 3. 精密度 vs 准确度(全文核心)

| 概念 | 含义 | 随 $k$ | 如何获得 |
|---|---|---|---|
| **精密度 precision** | 多次估计互相聚拢的程度(重复性) | $\propto 1/\sqrt{k}$(噪声主导时) | 直接从 50 次重采样的散布得到 |
| **准确度 accuracy** | 估计逼近真值的程度 | 受偏差地板限制,到平台后不再降 | **必须**有参考:房间角(物理)或结构光(亚 mm 锚) |

**预期曲线形状**:精密度先按 $k^{-0.5}$ 下降,到某 $k^\star$ 后**平台 = 偏差地板**。
- 斜率 −0.5 → 噪声主导,融合有效;
- 斜率偏缓(如 −0.3)→ **帧间相关**(静态相邻帧近似,有效独立样本 $k_{\text{eff}}<k$);
- 出现平台 → **偏差地板**(再加帧无用,需换方法/加靶标)。

> 找到 $k^\star$ 本身是核心产出之一:它告诉你「每台雷达采几帧就够」。

## 4. 实验要回答的问题

1. 单帧($k=1$)外参精密度是多少?(各传感器、各轴)
2. 融合 $k$ 帧后,精密度按什么规律改善?是否服从 $\sigma/\sqrt{k}$?偏差地板在哪?
3. 各传感器对比:机械 vs 固态 vs 结构光,曲线形状有何不同?
4. 点云本身的质量(平面 RMSE)随 $k$ 如何改善?(独立于配准的直接净化度量)
5. 绝对准确度:配准后房间角的 90° 二面角误差、平整度、角顶跨传感器一致性如何?
6. 实操结论:每台传感器达到某目标精密度需要多少帧?

## 6. 参考系层级(三 级 分 工)

这是实验能否区分精密度/准确度的关键设计。

| 层级 | 用谁 | 角色 | 看重什么 |
|---|---|---|---|
| **L1 全局世界系 / 主参考** | **QT128-融合**(外参=单位阵) | 定义坐标、所有 LiDAR 配进它 | 覆盖 360°、条件数、同模态 hub |
| **L2 局部高精度锚** | **结构光**(重叠区) | 校 LiDAR→QT128 链的**绝对偏差** | 亚 mm 准确度(近距) |
| **L3 物理真值** | **房间角(三平面)** | 绝对角度/平整度/角顶一致性 | 90° 二面角(可物理测量) |

### 6.1 为什么 QT128 当全局基准,而不是结构光
结构光更准(亚 mm vs QT128-融合 ~mm),但**不适合当全局基准**:
1. **覆盖/条件数**:结构光是前向锥 + 近距(0.6–4.4m),LiDAR 是 360°/远距。小重叠区配准 → 外参条件数差(lever arm 短、旋转弱约束),远离重叠区就是外推、精度劣化。
2. **模态匹配**:主任务是 LiDAR-LiDAR,LiDAR↔LiDAR 配准比 LiDAR→稠密结构光干净。
3. **循环**:要评估结构光自己的 $k$ 收益,它就是被测件,不能当自己的参考。
4. **参考精度「够用即可」**:测 LiDAR 精密度时瓶颈是 LiDAR 自身噪声(~cm),QT128-融合 ~mm ≪ cm 已够干净;结构光亚 mm 优势被浪费,而其覆盖短板会**主动伤条件数**。→ 全局基准角色,**覆盖比精度重要**。

### 6.2 结构光的正确角色:准确度锚(非全局系)
- **测精密度**:参考够干净即可 → QT128 够,结构光是 overkill。
- **测准确度**:参考要尽量接近真值 → 结构光(亚 mm 绝对深度)更接近真值。
- → 结构光当「重叠区局部真」,检验 LiDAR→QT128 链在重叠区的绝对偏差。精度优势用在刀刃上。

### 6.3 房间角(三平面 trihedron)
两平面墙角可用,但**三面交角的房间角**信息量最大:
- 每面拟合 → **平整度 RMSE = 点噪声**(独立于配准的直接度量);
- 面间二面角应 = 90° → **绝对角度误差**(物理可量,把「重复性」变「准确度」的硬锚);
- 三面交点(角顶)→ 唯一 3D 点,各传感器配准后是否一致 → **跨传感器配准准确度**。
- **坑**:角棱最脏(遮挡/边缘混合/flying pixel),量**离棱几厘米的平面区**。

## 7. 实验设计

### 7.1 融合帧数 $k$
$$k \in \{1,\ 4,\ 9,\ 16,\ 25,\ 36,\ 49,\ 64,\ 81\}\quad(\text{平方数, 专为检验 } \sigma/\sqrt{k})$$
- $k=1$:100 张单帧各自配准 → 100 个 $T_i$(单帧精密度)。
- $k>1$:每个 $k$ 做 **50 次随机重采样**(从该雷达的可用帧里随机选 $k$ 帧)→ 50 个融合外参。

### 7.2 固定参考系(隔离每台雷达)
- QT128 全 100 帧(或足够多)融合 → 干净参考云 = 世界系(单位阵)。
- **只变被评估雷达的帧**,QT128 参考固定 → 散布只反映该雷达,不混 QT128 噪声。
- 逐帧($k=1$)时:B 的第 $i$ 帧配到**固定**的 QT128-融合云(不是配到第 $i$ 帧 QT128,否则混入 QT128 单帧噪声)。

### 7.3 配准一致性(必备)
所有配准(逐帧 & 各 $k$)**同一初值**(§8.4 的粗配准标称外参)+ **同一 ICP 设置**(point-to-plane、相同对应距离、相同迭代上限)。否则散布混入「收敛随机性」,不是纯测量噪声。

### 7.4 统计:鲁棒 + 经典都报
每个 $k$ 的 50 个外参,对每个轴报:
- **均值 ± std**(经典,看主体);
- **中值 ± MAD/IQR**(鲁棒,抗 ICP 失败离群)。
两者分歧大 → 重尾/有失败;接近 → 分布干净(免费分布诊断)。

### 7.5 分轴
$$(t_x, t_y, t_z,\ \text{roll}, \text{pitch}, \text{yaw})$$
每个轴一条 $k$ 曲线。室内场景各轴约束**各向异性**(沿长墙平移、绕墙法向旋转常不可观测)→ 某些轴散布大且不随 $k$ 降(场景地板)。混成一个数会掩盖。

## 8. 净化方法(逐传感器)

### 8.1 机械雷达(禾赛/速腾)——角度域桶中值
- 禾赛:PCD 带 `ring` 字段 → 桶 = (ring, azimuth_bin)。每桶跨帧取中值。
- 速腾:无 `ring` → 由 xyz 算 (方位角, 俯仰角),分 bin 作桶。
- 输出:每射线一个干净点(比 $N$ 帧原始点更小更净)。

### 8.2 Livox(固态)——体素质心/中值 + SOR
- 累加全部点 → 3D 体素栅格 → 每体素质心(均值)或中值(边缘鲁棒)→ 统计离群剔除(SOR)。
- **对 Livox 累积是必需**(单帧 50k 点 rosette 太稀,不累积没法用);主力收益是**增密 + 离群剔除**,而非深度降噪。
- frame_cnt 恒 0:帧边界无意义(非一圈旋转),直接把 100 帧点全堆起来。

### 8.3 结构光——深度图逐像素中值
- 读 $N$ 张 `depth_*.png`(uint16 mm)→ 逐像素 $(u,v)$ 对有效帧(depth≠0)取中值 → 净化深度图 → 用内参反投影成点云。
- 等价:若 `points_*.pcd` 是像素光栅序,按 index 对齐取中值(均值情形等价于深度域)。
- 主力收益:边缘/flying pixel 清理(中值)+ 覆盖增密(零星有效像素补全)。

### 8.4 粗配准(标称外参,作 ICP 初值)
- 先用特征法(FPFH + RANSAC / Teaser++)或人工对齐,在高质量融合云上求各对的标称外参。
- 这是所有后续配准的**固定初值**,保证收敛到同一盆地。

## 9. 评估指标与预期输出

### 9.1 指标定义

| 指标 | 定义 | 量的是 | 期望 vs $k$ |
|---|---|---|---|
| **各轴外参散布** | 50 次重采样 $T_k$ 各轴的 std/MAD | 精密度 | $\propto k^{-0.5}$ 至平台 |
| **平面拟合 RMSE** | 已知平面区点-面距离 RMS | 点云噪声(独立于配准) | $\propto k^{-0.5}$ |
| **金标准收敛** | $\lVert T_k - T_{\text{gold}}\rVert$,$T_{\text{gold}}$=全帧融合 | 内部一致性 | 随 $k$ 单调降 |
| **留出残差** | 融合 $k$ 帧的 $T_k$ 套到未参与帧的残差 | 偏差/过拟合探针 | 与样本内残差对比 |
| **二面角误差** | 房间角两/三面拟合角 − 90° | 绝对角度准确度 | 常量(偏差地板) |
| **平整度** | 房间角各面平面 RMSE | 绝对点噪声 | 随 $k$ 降 |
| **角顶一致性** | 角顶点在各传感器配准后的散布 | 跨传感器配准准确度 | — |

### 9.2 预期图表
1. **精密度-$k$ 曲线**(log-log,每传感器每轴):核心图,验 $\sigma/\sqrt{k}$、看偏差地板。
2. **平面 RMSE-$k$ 曲线**(每传感器):直接净化效果。
3. **金标准收敛曲线**:$\lVert T_k-T_{\text{gold}}\rVert$ vs $k$。
4. **留出 vs 样本内残差**对比图。
5. **绝对准确度**:二面角误差柱状、平整度、角顶散布(按传感器)。
6. **传感器对比**:同图叠各传感器的精密度-$k$ 曲线。

### 9.3 金标准「数据太大」的澄清
$T_{\text{gold}}$ 不是更多数据,是**最优融合的产物**(小、干净)。它和房间角**分工**:金标准给内部一致性(收敛曲线),房间角给绝对真值。金标准自身也有偏差(ICP 收敛),**不能当真值**——正是所以要房间角。

## 11. 预期结果与陷阱(预判,别误读)

| 现象 | 解读 |
|---|---|
| 机械雷达 $k$ 曲线接近 $-0.5$ 斜率 | 单帧是完整一圈,噪声主导,融合有效 |
| Livox 逐帧散布很大、偶有失败 | 单帧 rosette 太稀 → **证明它必须融合**;曲线可能非纯 $1/\sqrt{k}$(增密主导) |
| 曲线斜率偏缓(如 −0.3) | 帧间相关,有效样本 $k_{\text{eff}}<k$;算自相关重画 σ vs $k_{\text{eff}}$ |
| 曲线平台 | 偏差地板;再加帧无用 |
| 某轴不随 $k$ 降 | 场景简并,该轴不可观测(沿长墙平移、绕墙法向旋转) |
| 大 $k$(如 81)50 组散布估计噪声大 | 81/100 帧高度重叠,试验强相关,正常 |
| 均值与中值分歧大 | 重尾,有 ICP 失败/离群,定位是哪台哪个 $k$ |

**有效独立样本**:静态相邻帧近似,$1/\sqrt{k}$ 是乐观上界。可由逐帧残差自相关估 $k_{\text{eff}}$,把曲线重画为 σ vs $k_{\text{eff}}$ 更接近理论 $1/\sqrt{N}$。

## 14. 术语速查

- **外参 extrinsic**:传感器间 6-DoF 刚体变换 $(R|t)$。
- **精密度 precision**:多次估计的聚拢程度(重复性),随 $k$ 以 $\sigma/\sqrt{k}$ 改善。
- **准确度 accuracy**:逼近真值的程度,受偏差地板限制,需参考才能定。
- **金标准 $T_{\text{gold}}$**:全帧最优融合的外参,内部一致性参考(有偏,非真值)。
- **桶 bucket**:同一世界点的跨帧聚合单元(机械=(ring,az);固态=voxel;结构光=像素)。
- **条件数 conditioning**:配准能多好地约束 6-DoF;重叠区小/lever arm 短 → 条件数差。
- **$k^\star$**:精密度曲线进入偏差平台的转折帧数 = 「采几帧够用」。
