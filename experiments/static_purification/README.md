# 静态多帧净化对外参标定的影响评估

> **一句话**:用 5 传感器 × 100 静态帧,定量刻画「融合 $k$ 帧」对雷达外参标定**精密度 / 准确度**的提升,找到每台传感器「采几帧够用」的转折点 $k^\star$,并严格区分**重复性(precision)**与**真值准确度(accuracy)**。
>
> 本文档 = 目标 + 原理(讨论定稿)+ 实验设计 + **待办工作清单(§五,按序逐项执行)**。
> 实现脚本后续放在本目录:`fuse.py`(净化)/ `register.py`(配准)/ `eval.py`(评估)+ 结果图。

---

## 一、目标

### 1.1 总目标
定量评估「静态多帧融合净化」对外参标定的收益,产出四样东西:
1. 每台传感器**精密度随融合帧数 $k$ 的曲线**(是否服从 $\sigma/\sqrt{k}$、偏差地板 $k^\star$ 在哪);
2. 每台**点云质量(平面拟合 RMSE)随 $k$ 的改善**(独立于配准的直接净化度量);
3. **绝对准确度**校验(配准后**三面角(近似垂直、一面是放置的板)**的平整度 RMSE / 角顶跨传感器一致性 / 角度[需实测三面角,否则退化为跨传感器一致性];结构光重叠区亚 mm 锚);
4. 实操结论:**每台采几帧够用**(达目标精密度所需帧数)。

### 1.2 小目标与度量指标(细化,每个都要测)
把总目标拆成 4 组小目标,每组列出**具体可测指标**(定义/画法见 §六):

**G1 · 外参精密度(precision)及其随 $k$ 的规律**
- G1.1 **平移精密度**:$t_x,t_y,t_z$ 各自的 std 与 MAD(50 次重采样),vs $k$。
- G1.2 **旋转精密度**:$\text{roll,pitch,yaw}$ 各自的 std 与 MAD,vs $k$。
- G1.3 **$\sigma/\sqrt{k}$ 律检验**:精密度-$k$ 的 log-log 斜率(噪声主导时应 −0.5);量化偏离。
- G1.4 **偏差地板 $k^\star$**:精密度进入平台的转折帧数(再加帧无用)。
- G1.5 **有效独立样本 $k_{\text{eff}}$**:由逐帧残差自相关估;把曲线重画为 σ vs $k_{\text{eff}}$ 更近理论 $1/\sqrt{N}$。
- G1.6 **分布诊断**:mean vs median 分歧量(分歧大=重尾/有 ICP 失败)。
- G1.7 **单帧基线($k=1$)**:100 个 $T_i$ 的散布(曲线最左端)。

**G2 · 点云质量(独立于配准的直接净化度量)**
- G2.1 **平面拟合 RMSE**(公共平面区,点-面距离 RMS)vs $k$ → 点噪声 $\sigma$。
- G2.2 **密度 / 覆盖**(points/area 或 voxel 填充率)vs $k$。
- G2.3 **离群率**(SOR 剔除点占比)vs $k$。
- G2.4 **边缘 / flying-pixel 抑制**(结构光、Livox;边缘处点离散度)vs $k$。

**G3 · 准确度(accuracy,需参考;精密度再好也替代不了)**
- G3.1 **金标准收敛** $\lVert T_k-T_{\text{gold}}\rVert$:平移(m)+ 旋转(°),vs $k$。⚠️ 金标准有偏,只是内部一致性。
- G3.2 **留出残差**:用 $k$ 帧融合的 $T_k$ 套到**未参与帧**的残差,对比**样本内(配准)残差** → 差距=过拟合/偏差(target-free 偏差探针)。
- G3.3 **三面角参考**(三面**近似**垂直, 其中一面是放置的板, 非绝对 90°):
  - 各面**平整度 RMSE**(板/墙应平 → 绝对点噪声,**不依赖角度**)。
  - **角顶**(三面交点)跨传感器一致性(绝对位置收敛)。
  - **角度**:若**实测**三面角(角尺/量角器),则 LiDAR 测角 vs 实测 = 绝对角度误差;否则退化为跨传感器角度**一致性**(不能默认 90°)。
  - 即便 ≈90°,三面角仍给配准良好 6-DoF 约束(条件数好)。
- G3.4 **结构光锚**:重叠区 LiDAR ↔ 结构光 几何吻合度(亚 mm 参考,校 LiDAR 链偏差)。
- G3.5 **各轴准确度各向异性**(室内某些轴场景不可观测)。

**G4 · 综合与实操**
- G4.1 每传感器 $k^\star$ + **帧数建议**(达目标精密度所需)。
- G4.2 **传感器类型对比**(机械 / 固态 / 结构光)曲线与标度差异。
- G4.3 各轴各向异性解读(哪些轴被场景简并、不可观测)。

### 1.3 要回答的 6 个问题(头条;细节指标见 §1.2 的 G1–G4)
1. 单帧($k=1$)外参精密度是多少?(各传感器、各轴 $t_x,t_y,t_z,\text{r,p,y}$)→ G1.7
2. 融合 $k$ 帧后精密度按什么规律改善?是否 $\sigma/\sqrt{k}$?偏差地板 $k^\star$ 在哪?→ G1.3、G1.4
3. 各传感器对比:机械式(禾赛/速腾)vs 固态(Livox)vs 结构光,曲线形状有何不同?→ G4.2
4. 点云本身质量(平面 RMSE)随 $k$ 如何改善?→ G2.1
5. 绝对准确度:三面角(近似垂直)的平整度、角顶一致性、角度如何?→ G3.3
6. 实操结论:每台达到某目标精密度需要多少帧?→ G4.1

## 三、原理(为什么这样做)

### 3.1 静态净化:$\sigma/\sqrt{N}$ 与各传感器「桶」
静态 + 固定安装下,同一(射线/像素)在 $N$ 帧里采到同一世界点的 $N$ 个带噪样本,取均值/中值:$\sigma_{\text{fused}}=\sigma_{\text{single}}/\sqrt{N}$。各传感器「桶」不同:

| 类型 | 扫描特性 | 净化域 | 桶定义 |
|---|---|---|---|
| 机械(禾赛/速腾) | 固定线束旋转,重复 | 角度域 | (ring, azimuth);速腾无 ring → (方位角 bin, 俯仰角 bin) 由 xyz 反算 |
| 固态(Livox) | 双棱镜 rosette,非重复 | 空间体素域 | 3D voxel(无固定射线,累积填满视场) |
| 结构光(FM815) | 全像素深度图 | 深度图域 | 像素 $(u,v)$;逐像素中值再反投影 |

> 三者同构(同一世界点多帧统计),桶的几何不同。结构光最规则稠密,时域中值如长曝光。**边缘跳变处桶会跨帧双峰**(机械边缘桶、结构光 flying pixel)→ 用**中位数**,别用均值(造鬼点);量离棱几厘米的平面区。

### 3.2 精密度 ≠ 准确度(全文核心)

| 概念 | 含义 | 随 $k$ | 如何获得 |
|---|---|---|---|
| **精密度** | 多次估计互相聚拢(重复性) | $\propto 1/\sqrt{k}$(噪声主导时) | 50 次重采样散布直接得 |
| **准确度** | 逼近真值 | 受偏差地板限制,到平台后不降 | **必须**有参考:房间角(物理)/ 结构光(亚 mm 锚) |

精密度先按 $k^{-0.5}$ 下降,到 $k^\star$ 后**平台 = 偏差地板**。斜率 −0.5 → 噪声主导;偏缓 → 帧间相关($k_{\text{eff}}<k$);平台 → 偏差地板。**$k^\star$ 是核心产出**。系统偏差不随 $k$ 减小——$\sigma/\sqrt{k}$ 是精密度律,不是准确度律。

### 3.3 先融合再配准 > 逐帧配准再平均
- **方案 A(参数层平均)**:逐帧配准 → $N$ 个 $T_i$ → 平均。只降方差,不降偏差(单帧稀疏+噪声致配准系统性偏差,$N$ 个偏的均值仍偏);还有旋转平均的坑、帧间相关高估 $\sigma/\sqrt{N}$。
- **方案 B(测量层平均,采用)**:先融合成干净云 → 一次配准。靠稠密化降偏差 + 降方差,更接近最大似然。
- 方案 A 的唯一价值:$T_i$ 的散布作**精密度诊断**。→ **方案 B 出结果 + 方案 A 的分布报精密度**。

### 3.4 参考系三级层级(区分精密度/准确度的关键)

| 层级 | 用谁 | 角色 | 看重 |
|---|---|---|---|
| **L1 全局世界系** | **QT128-融合**(外参=单位阵) | 定义坐标,所有 LiDAR 配进它 | 覆盖 360°、条件数、同模态 hub |
| **L2 局部高精度锚** | **结构光**(重叠区) | 校 LiDAR→QT128 链的绝对偏差 | 亚 mm 准确度(近距) |
| **L3 物理参考** | **三面角(近似垂直, 一面是板)** | 平整度 / 角顶一致性 / (角度需实测) | 三平面给良好 6-DoF 约束;**不默认 90°** |

**为什么不用结构光当全局基准**:它前向锥+近距(0.6–4.4m),与 360°/远距 LiDAR 重叠小 → 条件数差、外推劣化;且评估结构光自身时它不能当自己的参考。→ QT128 管全局条件数(精密度),结构光管局部绝对偏差(准确度),房间角兜底真值。

## 四、实验设计

- **融合帧数** $k \in \{1,4,9,16,25,36,49,64,81\}$(平方数,专为验 $\sigma/\sqrt{k}$)。$k=1$:100 单帧各配准 → 100 个 $T_i$。
- **每个 $k$**:从该传感器可用帧里**随机选 $k$ 帧** × **50 次**重采样 → 50 个融合外参 $T_k$。
- **固定参考系**:QT128 全帧融合 = 世界系(单位阵),固定不变;只变被评估传感器的帧 → 散布只反映该传感器。
- **配准一致性**:所有配准(逐帧 & 各 $k$)**同一初值**(标称外参)+ **同一 ICP 设置**(point-to-plane、同对应距离、同迭代上限)。
- **统计**:每个 $k$ 报**均值±std** 和 **中值±MAD**(两者分歧大 → 重尾/有 ICP 失败)。
- **分轴**:$(t_x,t_y,t_z,\text{roll,pitch,yaw})$ 各一条 $k$ 曲线(室内各轴约束各向异性)。

### Phase 5 · 准确度(→ 依赖 Phase 4)

- [ ] **5.3 三面角 + 结构光锚** → **G3.3、G3.4、G3.5**

## 七、预期结果与陷阱

| 现象 | 解读 |
|---|---|
| 机械 $k$ 曲线近 −0.5 斜率 | 单帧是完整一圈,噪声主导,融合有效 |
| Livox 逐帧散布大、偶失败 | 单帧 rosette 太稀 → 证明必须融合;曲线可能非纯 $1/\sqrt{k}$(增密主导) |
| 斜率偏缓(如 −0.3) | 帧间相关,$k_{\text{eff}}<k$;算自相关重画 σ vs $k_{\text{eff}}$ |
| 曲线平台 | 偏差地板,再加帧无用 |
| 某轴不随 $k$ 降 | 场景简并,该轴不可观测(沿长墙平移、绕墙法向旋转) |
| 大 $k$(如 81)50 组散布噪声大 | 81/100 高度重叠,试验强相关,正常 |
| 均值与中值分歧大 | 重尾,有 ICP 失败/离群,定位哪台哪个 $k$ |

**(1) 有效独立样本**:静态相邻帧近似,$1/\sqrt{k}$ 是乐观上界;由逐帧残差自相关估 $k_{\text{eff}}$,把曲线重画为 σ vs $k_{\text{eff}}$ 更近理论 $1/\sqrt{N}$。
**(2) 场景简并**:大平面墙/长走廊使部分轴不可观测 → 精度各向异性;需场景含三维角点/边沿且被多传感器共看。
**(3) 若缺房间角**:绝对准确度做不了,只能报精密度 + 金标准收敛(内部一致性);此时按重采清单补一个三面角进公共视场。

## 八、依赖与实现备注

- **配准/ICP**:优先 **open3d**(`registration_icp`、`registration_ransac`、FPFH);本机 PCL/VTK 链接坏(见根 `README.md` §6),不用 PCL。
- **点云读写**:open3d 读 PCD;或沿用 `tools/` 的 ASCII PCD 解析;`tools/pcd_to_ply.py` 可转 PLY 给 CloudCompare 核对。
- **速腾无 ring**:由 xyz 算 (az, el) 分 bin 当桶。
- **结构光反投影**:需 FM815 IR 相机内参(`sensors/structured_light/STRUCTURED_LIGHT.md`)。
- **计算量**:数百次 ICP(每 ~4-40 万点),工作站可跑,可并行。

## 九、术语

- **外参 extrinsic**:传感器间 6-DoF 刚体变换 $(R|t)$。
- **精密度 precision**:多次估计聚拢程度(重复性),随 $k$ 以 $\sigma/\sqrt{k}$ 改善。
- **准确度 accuracy**:逼近真值程度,受偏差地板限制,需参考才能定。
- **金标准 $T_{\text{gold}}$**:全帧最优融合外参,内部一致性参考(有偏,非真值)。
- **桶 bucket**:同一世界点的跨帧聚合单元(机械=(ring,az);固态=voxel;结构光=像素)。
- **条件数 conditioning**:配准能多好约束 6-DoF;重叠小/lever arm 短 → 差。
- **$k^\star$**:精密度曲线进入偏差平台的转折帧数 =「采几帧够用」。
